========================================
      💬 Cf 聊天助手 v2.2 - 使用说明书
========================================

【写在前面】
历经多轮迭代，Cf 助手迎来了 v2.2 版本。它不仅拥有视觉多模态、对话推演、风格克隆等进阶功能，还支持云端、校园、本地三种 API 通道，你可以根据自己的实际情况灵活选择。

----------------------------------------
【第一步：首次运行与环境配置】
----------------------------------------
1. 解压整个文件夹到一个没有中文和空格的路径（比如 D:\Cf助手）。
2. 右键点击 “1-首次启动（检查环境）.bat”，选择 “以管理员身份运行”。
3. 脚本会自动检测 Python 环境并安装所需的依赖库（包括视觉分析所需的 Pillow 库），此过程约需 1-2 分钟，请耐心等待。
4. 安装完成后，悬浮窗会自动弹出。如果黑框出现红色报错，请截图发给作者。

----------------------------------------
【第二步：配置 API（三选一）】
----------------------------------------
打开 Cf 助手，点击右上角 ⚙️ 进入设置，根据你的需求选择以下任意一种模式：

▶ 模式 A：云端 API（推荐所有人使用，稳定且快）
  - 去 DeepSeek 官网 (platform.deepseek.com) 注册并充值（10元能用很久）。
  - 在“云端 API”选项卡填入：
    * API 地址：https://api.deepseek.com/v1
    * API Key：你的 DeepSeek 密钥
    * 模型名称：deepseek-chat
  - 保存后，将主界面右上角下拉框切换为“云端”。

▶ 模式 B：校园 API（交大师生专属，额度极高）
  - 仅限校内网络（或连学校 VPN）使用。
  - 在“校园 API (视觉)”选项卡填入：
    * API 地址：https://models.sjtu.edu.cn/api/v1
    * API Key：你申请的 sk- 开头的密钥
    * 模型名称：推荐 deepseek-chat 或 qwen3.8-27b
  - 保存后，将主界面右上角下拉框切换为“校园”。

▶ 模式 C：本地 Ollama（完全免费、隐私绝对安全）
  - 需要电脑安装 Ollama 并下载模型（如 deepseek-r1:14b）。
  - 在“本地 Ollama”选项卡确认：
    * 地址：http://localhost:11434/v1
    * API Key：ollama
    * 模型名称：你下载的模型名
  - 保存后，将主界面右上角下拉框切换为“本地”。
  * 注意：本地模型通常不支持视觉（截图分析），且推理速度取决于你的电脑显卡。

----------------------------------------
【第三步：日常启动与核心操作】
----------------------------------------
🔑 快捷键：
- Ctrl+Shift+J ：提取输入框或剪贴板的内容，开始分析
- Ctrl+Shift+S ：打开设置面板（配置API、换背景、调记忆）
- Ctrl+Shift+Q ：彻底退出 Cf 助手

🖱️ 悬浮窗操作：
- 拖动窗口：按住窗口任意空白处拖动
- 调整大小：拖动右下角绿色小方块
- 关闭窗口：点击右上角 ✖ 按钮，或按 Esc 键
- 复制回复：点击分析结果下方的任意回复按钮，自动复制到剪贴板

🚀 日常启动：
配置完毕后，以后每次使用直接双击 “2-日常启动（静默版）.bat” 即可（黑框一闪而过，直接弹出悬浮窗）。

----------------------------------------
【第四步：v2.2 进阶玩法详解】
----------------------------------------
1. 👤 对象人设设定
   - 顶栏点击 👤 按钮，给当前的聊天对象写个简介（例如：“男，25岁，好哥们，喜欢互怼” 或 “女，50岁，妈妈，比较传统”）。
   - AI 会根据人设自动调整语气。如果人设是长辈或领导，AI 会自动降低极端风格的概率，防止你社死。

2. 🕵️ 群友透视与视觉分析（需使用支持视觉的模型）
   - 在微信/QQ截图后，直接按 Ctrl+Shift+J，程序会自动读取剪贴板图片，识别聊天记录中的文字和昵称。
   - 在“水群模式”下截图分析，结果上方会多出一个黄色的【🕵️ 群友透视】框，帮你分析每个群友此刻的心态标签（如：急了、阴阳怪气、纯路人）。

3. 💡 行动建议与预测对方
   - 分析结果中间会显示【💡 行动建议】，告诉你除了回复之外，线下该做什么（比如：去翻一下昨天的聊天记录、赶紧去订个餐厅）。
   - 每个回复按钮下方都附带【⤷ 预测对方：xxx】，让你提前预判这句话发出去后对方会怎么破防。

4. 🎭 个人风格克隆
   - 在设置 -> “个人风格克隆”中，粘贴你以前在群里发的几句真实语录。
   - 点击“✨ 一键提取我的风格”，AI 会自动总结你的说话习惯并填入提示词。
   - 以后生成的回复，会带有你专属的腔调（比如爱用波浪号、爱说“绝了”、喜欢自黑等）。

5. 🧠 无限上下文记忆
   - 在设置 -> “高级设置”中，可以勾选“开启无限上下文记忆”。
   - AI 能记住你们过去几十轮的完整对话，分析会更加连贯和精准。如果觉得 Token 消耗太快，可以随时在右下角点击“🧠 清空当前记忆”。

6. ⚙️ 独立控制极端风格
   - 在设置 -> “高级设置”中，新增了三个独立的开关：
     【允许生成发疯型回复】
     【允许生成更疯型回复】
     【允许生成冒犯型回复】
   - 你可以根据需要随时关闭，关闭后 AI 只会生成稳妥、幽默、高冷的正常回复，彻底杜绝不小心发给长辈或领导的尴尬。

----------------------------------------
【常见问题排错指南】
----------------------------------------
1. 双击启动没反应 / 快捷键失效？
   解答：权限不够，请右键“以管理员身份运行”启动脚本。如果被 Windows Defender 拦截，请前往“保护历史记录”恢复并添加信任。
2. 黑框提示“No module named 'PIL'”？
   解答：说明缺少视觉分析依赖，请重新运行 “1-首次启动（检查环境）.bat”，确保安装成功。
3. 一直显示“分析失败”？
   解答：云端模式检查API余额和Key；校园模式确认连了校内网/VPN；本地模式确保Ollama已启动且模型名正确。
4. 水群模式分不清谁在说话？
   解答：微信直接框选复制不带昵称。请使用截图功能，或在微信中右键群友发言 -> 引用，再复制。
5. 换了背景图没保存？
   解答：选好背景后，务必点击设置最下方的“保存配置”按钮。

----------------------------------------
【⚠️ 特别警告】
----------------------------------------
1. 账号安全：所有数据（API Key、历史记录、上下文、背景图）都保存在你电脑本地（C:\Users\你的用户名\.cf_assistant），绝对不会上传云端。
2. 分享注意：如果你要将此工具分享给朋友，千万不要直接把自己的 config.json 发过去（那包含你的 API Key）。让朋友自己申请 API Key 填入。
3. 娱乐尺度：“发疯型”、“更疯型”和“冒犯型”仅供好友互怼娱乐，请勿对长辈、领导或陌生人使用。

祝你在群聊和私聊里如鱼得水，把把都能打出完美输出！
