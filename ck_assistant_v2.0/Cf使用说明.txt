========================================
        💬 Cf 聊天助手 - 使用说明书
========================================

欢迎使用 Cf 聊天助手！这是一个支持单聊/水群、云端API/本地大模型双通道、支持6种回复风格的智能辅助工具。

----------------------------------------
【第一步：首次运行配置】
----------------------------------------
1. 解压整个文件夹到一个没有中文和空格的路径（比如 D:\Cf助手）。
2. 找到并右键点击 “1-首次启动（检查环境）.bat”，选择 “以管理员身份运行”。
3. 此时会弹出一个黑框，它会自动检查环境并安装依赖库（可能需要1-2分钟），请耐心等待。
4. 依赖安装完成后，黑框会自动启动 Cf 助手，并弹出悬浮窗。
5. 如果黑框里出现红色报错，请截图发给作者。

【注意】此黑框不能直接关掉，最小化即可。如果关掉，程序也会退出。

----------------------------------------
【第二步：日常使用方式】
----------------------------------------
确认首次配置成功后，以后每次使用：
1. 直接双击 “2-日常启动（静默版）.bat”。
2. 黑框会一闪而过，直接弹出漂亮的悬浮窗。
3. 如果发现快捷键突然没反应了，请右键点击 “2-日常启动（静默版）.bat” -> 以管理员身份运行。

----------------------------------------
【第三步：配置 API（首次必做）】
----------------------------------------
云端模式需要自备 API Key，推荐使用 DeepSeek（非常便宜，充10元能用很久）：
1. 浏览器访问 platform.deepseek.com，注册并实名。
2. 在“API Keys”页面点击“创建 API key”，复制以 sk- 开头的密钥。
3. 回到 Cf 助手悬浮窗，点击右上角 ⚙️ 按钮。
4. 在“云端 API”选项卡的 API Key 栏粘贴，点击保存。
5. 如果使用本地模型：需提前安装 Ollama 并下载 deepseek-r1:14b，在设置里切换到“本地”。

----------------------------------------
【核心快捷键】
----------------------------------------
Ctrl + Shift + J ：提取输入框或剪贴板的内容，开始分析
Ctrl + Shift + S ：打开设置面板（配置API、换背景、切模式）
Ctrl + Shift + Q ：彻底退出 Cf 助手

【悬浮窗操作】
- 拖动窗口：按住窗口任意空白处拖动
- 调整大小：拖动右下角绿色小方块
- 关闭窗口：点击右上角 ✖ 按钮，或按 Esc 键
- 复制回复：点击分析结果下方的任意回复按钮，自动复制到剪贴板

----------------------------------------
【常见问题排错】
----------------------------------------
1. 双击没反应 / 快捷键失效？
   解答：权限不够，请右键以管理员身份运行脚本。
2. 一直被 Windows 拦截？
   解答：Windows Defender 会误报，请前往“保护历史记录”恢复并添加信任。
3. 水群模式分不清谁在说话？
   解答：微信直接框选复制不带昵称。请右键群友发言 -> 引用，再复制。
4. 换了背景图没保存？
   解答：选好背景后，务必点击设置最下方的“保存配置”按钮。
5. 账号安全吗？
   解答：所有数据（包括 API Key、历史记录、背景图）都保存在你电脑本地（C:\Users\你的用户名\.cf_assistant），绝对隐私。
