========================================
    💬 Cf 助手 v2.4 · 全平台使用说明书
========================================

【写在前面】
历经多轮迭代，Cf 助手现在拥有三个形态：桌面悬浮窗版、Web 常规版、以及沉浸式 Galgame 版。三者共用同一个“大脑”（engine.py）和同一套配置，你在任何一端修改设置，另外两端都会同步生效。

v2.4 版本迎来了“灵魂注入”级别的升级：全新加入了【心情注入】和【前情提要】功能，让 AI 的回复不再干巴巴，而是能精准贴合你此刻的情绪与真实的聊天背景。

----------------------------------------
【第一步：环境安装】
----------------------------------------
1. 安装 Python（如果还没装）。
2. 在项目文件夹打开终端（PowerShell），运行以下命令安装全部依赖：
   pip install openai pyperclip keyboard PyQt5 pillow fastapi uvicorn

----------------------------------------
【第二步：桌面悬浮窗版 (v2.4)】
----------------------------------------
▶ 启动方式：
  双击 “2-日常启动（静默版）.bat”（或者右键“以管理员身份运行”以确保全局快捷键生效）。程序会直接以无边框悬浮窗形式弹出。

▶ 核心快捷键：
  - Ctrl+Shift+J ：优先分析输入框内容（含截图）；如果输入框为空，则自动读取剪贴板内容分析。
  - Ctrl+Shift+S ：打开设置面板。
  - Ctrl+Shift+Q ：彻底退出 Cf 助手。

▶ 窗口交互：
  - 拖动窗口：按住窗口任意空白处拖动。
  - 调整大小：拖动右下角绿色小方块。也可以在设置 -> 高级设置里调整输入框高度（80-400px）。
  - 最小化到任务栏：点击右上角 ➖。
  - 最小化到系统托盘：点击右上角 ✖（程序不退出，而是缩到右下角托盘区，像 QQ 和网易云一样）。
  - 唤出托盘：双击右下角的 “Cf” 图标，或右键 -> 显示主界面。

▶ v2.4 核心新增功能：
  - 🎭 心情注入（主界面下拉框）：你可以随时选择或手输当前的心情（如：烦躁、开心、委屈、发疯）。AI 会根据你的心情调整回复的语气和情绪色彩。
  - 📖 前情提要（主界面按钮）：点击后输入目前对话的背景（例如：昨晚打游戏没回消息）。AI 会结合这个背景信息，避免“答非所问”或“没有上下文”。

▶ 桌面端其他特色功能：
  - 截图分析：在微信/QQ截图后，直接按 Ctrl+Shift+J，程序会自动读取剪贴板图片。
  - 多 API 配置管理：设置 -> API 配置管理，可自由添加、修改、删除多套配置。
  - 对象人设设定：顶栏“👤 对象设定”按钮，给当前对象写简介（如“长辈”、“好哥们”），AI 会自动调整语气。
  - 个人风格克隆：设置 -> 个人风格克隆，粘贴你的历史发言，一键提取你的说话风格。
  - 极端风格独立开关：设置 -> 高级设置，可独立控制是否生成“发疯型”、“更疯型”、“冒犯型”回复。

----------------------------------------
【第三步：Web 常规助手版（浏览器/手机）】
----------------------------------------
▶ 启动方式：
  在项目文件夹运行：python api.py
  看到 “Uvicorn running on http://0.0.0.0:8000” 后，打开浏览器访问：
  电脑端：http://localhost:8000
  手机端：见下方【手机访问排错指南】。

▶ 界面操作：
  - 顶栏下拉框可切换不同的会话（如“张三”、“摸鱼群”）。
  - 在输入框上方可设置“🎭 心情”和“📖 前情提要”。
  - 在输入框中粘贴聊天记录，点击“🚀 开始分析”。
  - 分析完成后，下方会显示好感度、危险等级、行动建议，以及多个回复选项。
  - 点击任意回复选项按钮，会自动复制到剪贴板。

----------------------------------------
【第四步：Web Galgame 沉浸式版】
----------------------------------------
▶ 启动方式：
  同样运行 python api.py 后，在浏览器访问：
  电脑端：http://localhost:8000/galgame
  手机端：http://电脑局域网IP:8000/galgame

▶ 界面设计：
  - 顶栏包含“会话切换”、“📖 前情提要”和“💾 存档”按钮。
  - 中央是对话气泡，下方有“❤️ 好感度”和“⚠️ 危险度”状态栏。
  - 底部有“💡 行动建议”卡片和像 Galgame 选项一样的回复按钮（带有风格标签和“预测对方反应”）。
  - 输入区上方同样包含“🎭 心情”设置。

▶ 剧情存档系统：
  1. 分析完成后，点击“💾 保存当前剧情到存档”，输入名字。
  2. 点击顶栏“💾 存档”按钮，会弹出存档面板，展示你为当前会话保存的所有剧情节点（包括时间、当时的好感度和危险度）。
  3. 点击任意存档的“📂 读档”按钮，会完整恢复当时的对话气泡、状态栏、行动建议和所有选项。
  4. 每个存档可单独删除，底部也有“清空全部存档”按钮。
  *注意：存档按会话隔离，你为“张三”和“李四”保存的剧情各自独立。

【第五步：API 配置指南（三种模式通用）】
----------------------------------------
所有模式共享同一份配置文件（C:\Users\你的用户名\.cf_assistant\config.json）。
Cf 助手兼容所有兼容 OpenAI 格式的 API，你可以根据自己拥有的资源来配置：
  ▶ 云服务商 API：如 DeepSeek、Kimi、通义千问等。填入对应的 API 地址（如 https://api.deepseek.com/v1），以及对应平台申请的 API Key。
  ▶ 校园 API：部分高校为师生提供大模型 API。请根据你所在学校网络信息中心提供的文档，填写对应的 API 地址、Key 和模型名称。
  ▶ 本地 Ollama / LM Studio：如果你在本地部署了模型，填入本地地址（如 http://localhost:11434/v1），API Key 填 ollama 或任意字符，模型名填你下载的模型（如 deepseek-r1:14b）。

【第六步：手机访问排错指南（Web 版）】
----------------------------------------
很多用户反映手机连不上电脑的 Web 服务，这里总结了 100% 能解决的排查方案：
1. 确认手机和电脑是否在同一 WiFi 下。如果手机用流量、电脑连 WiFi，是绝对访问不了的。
2. 获取正确的电脑 IP 地址。在电脑终端输入 ipconfig，找到“无线局域网适配器 WLAN”下的 IPv4 地址（通常是 192.168.x.x 或 10.x.x.x）。
3. 手机浏览器输入格式必须正确：http://电脑IP:8000（例如 http://192.168.1.5:8000），不要用 https，不要用 localhost。
4. 如果手机显示“ERR_CONNECTION_FAILED”，大概率是校园网/公司网络开启了“AP隔离”，导致同一 WiFi 下的设备互相无法访问。此时请将电脑连接至手机开启的热点（个人热点无隔离限制），再重新获取 IP 访问。
5. 如果依然失败，请检查 Windows 防火墙。去“Windows 安全中心” -> “防火墙和网络保护” -> “允许应用通过防火墙”，确保 python.exe 的“专用”和“公用”都被打勾。
6. 跨网络远程访问：如果想在任意网络下访问你电脑的服务，可以使用 cpolar 或 ngrok 等内网穿透工具，把本地 8000 端口映射到公网，手机输入公网网址即可。

----------------------------------------
【常见问题排错】
----------------------------------------
1. 桌面端快捷键没反应？
   解答：右键点击启动脚本，选择“以管理员身份运行”。
2. 双击 exe 或运行脚本没反应？
   解答：如果被 Windows Defender 拦截，请去“保护历史记录”恢复并添加信任。
3. API 响应慢 / 一直转圈？
   解答：v2.4 已加入请求防抖和图片压缩。如果依然慢，建议在设置中切换为响应速度更快的轻量模型，或把上下文记忆轮数调小（设置 -> 高级设置）。
4. 桌面端或 Web 端提示“分析失败”？
   解答：云端模式检查 API Key 和账户余额；校园模式检查是否在校内网/VPN 环境下；本地模式确保 Ollama 已启动且模型名正确。
