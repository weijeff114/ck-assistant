【一、本阶段已完成的功能】
--------------------------------------------------------------------------------
1. 「联网搜索」：engine.web_search(query, max_results)
   - 多引擎自动 fallback：DuckDuckGo → Bing → 百度
   - 单引擎失败不抛异常，保证主流程不断
   - 返回结构：list[ {"title", "body", "href"} ]

2. 「AI 自动写书」：engine.auto_write_lorebook_from_topic(
                             topic, book_name=None, max_results=5)
   - 流程：搜索主题 → 组装语料（_join_search_text，限长6000字符）→
           AI 提炼 JSON（description/terms/memes/blacklist）→
           经 save_lorebook 落盘到世界书配置
   - 返回：dict { name, description, terms, memes, blacklist, ... }
           失败返回 {"error": "..."}

3. 「UI 工作台」：ui_lorebook.py 内新增
   - 输入区：topic_input（QLineEdit）
   - 按钮：btn_ai("AI自动写书") -> 绑定 self.on_auto_write
           btn_meme("联网查梗") -> 绑定 self.on_web_meme
   - 结果区：mode_output（QPlainTextEdit/QTextEdit 只读）
   - on_auto_write ：调 engine.auto_write_lorebook_from_topic
   - on_web_meme   ：调 engine.web_search(word, max_results=5)
                     在子线程执行（避免界面卡死）

4. 新增辅助函数
   - engine._join_search_text(results, max_chars=6000)
     把搜索结果拼成一段供 LLM 阅读的语料
