【写在前面】
历经多轮迭代，Cf 助手从桌面悬浮窗起步，如今已拥有三大形态：
  1. 桌面悬浮窗版 —— 最常用的主力形态，常驻桌面，随叫随到。
  2. Web 常规版     —— 浏览器/手机均可访问，无需安装。
  3. 沉浸式 Galgame 版 —— 恋爱模拟交互式界面，适合长剧情聊天。

三个形态共用同一颗"大脑"（engine.py）和同一套配置。
你在任何一端修改设置，另外两端都会同步生效——换皮肤不换人设。

多世界书（知识包）系统让你为不同会话挂载不同的世界观设定，
并内置【AI 自动写书】和【联网查梗】，让知识积累变得一键化。


================================================================================
一、环境安装（首次使用必看）
================================================================================

1. 安装 Python（若未安装，请前往 python.org 下载 3.9+）。
   注意：本机实测可用的是 miniconda 的 Python 3.14，PyQt5 正常。

2. 在项目根目录打开终端（PowerShell），运行：

   pip install -r requirements.txt

   （等价于：pip install openai pyperclip keyboard PyQt5 pillow fastapi uvicorn
     beautifulsoup4 duckduckgo_search httpx）

   如果用的是 conda 环境，请先激活：
   conda activate cf_env

3. 双击[1-首次启动（检查环境）.bat]，脚本会自动检查依赖是否齐全，
   缺失项会给你明确提示。检查通过后即可使用。

【快速测活套路】（可选）
   在项目目录执行：
   python -c "from engine import web_search; print(web_search('测试',1))"
   能打印出一串搜索结果字典（title/body/href 都有内容）即代表网络/依赖正常。


================================================================================
二、三形态启动方式
================================================================================

▶ 桌面悬浮窗版（推荐）
   双击[2-日常启动（静默版）.bat]
   ▸ 若无边框弹窗出现，且右下角托盘出现图标，即启动成功。
   ▸ 过程中会生成 cf_app_log.txt 记录运行日志（报错排查看这个文件）。

▶ Web 常规版
   在项目目录运行： python api.py
   看到 "Uvicorn running on http://0.0.0.0:8000" 后：
   ▸ 本机访问：  http://localhost:8000
   ▸ 手机访问：  http://电脑局域网IP:8000
   （IP 获取方法：终端输入 ipconfig，找到[无线局域网适配器 WLAN]下的 IPv4 地址）

▶ Web Galgame 沉浸式版
   在常规版运行成功后，浏览器访问： http://localhost:8000/galgame
   ▸ 界面会以"对话气泡 + 好感度 + 危险度 + 选项按钮"的形态呈现，
     像玩 Galgame 一样做选择聊天。

   ▸ Web 版注意：api.py 必须在项目目录下启动（它要读同目录的 index.html /
     galgame.html）；只在内网给手机用的话，防火墙放行 python.exe 即可。

三、核心快捷键（桌面版全局生效）
================================================================================

  Ctrl+Shift+J  优先分析输入框内容（含截图）；
                若输入框为空，则自动读取剪贴板内容分析。
  Ctrl+Shift+S  打开设置面板（API 配置 / 人设 / 心情等）。
  Ctrl+Shift+Q  彻底退出 Cf 助手。

  ⚠ 温馨提示：建议右键[2-日常启动（静默版）.bat]->[以管理员身份运行]，
    以确保全局快捷键在任意窗口下都能抢到焦点。


================================================================================
四、五步轻松上手（以桌面版为例）
================================================================================

步骤1：粘贴聊天记录
  将你和 TA 的聊天内容整段放入输入框（微信/QQ 直接复制即可）。

步骤2：可选 · 带上截图
  把聊天截图复制到剪贴板，或直接拖入输入框。系统会优先解析截图。

步骤3：设定"游戏环境"
   ▸ 心情（[心情]）：在顶栏下拉框选择或手动输入（烦躁、开心、委屈、发疯......）。
     选择后，AI 会调整回复的语气和情绪色彩。
   ▸ 前情提要（[前情]）：点击按钮，输入当前剧情背景
     （例如：昨晚打游戏没回消息）。避免 AI 答非所问。
   ▸ 对象设定（人物名片）：点击顶栏按钮，给 TA 写简介
     （如"高冷学长"、"发疯发小"），AI 会自动切换人设语气。

步骤4：点击[[启动] 开始分析]
  系统会评估：
  ▸ [好感] 好感度（0-100）：你们的关系进度条
  ▸ [注意] 危险等级：这句话是否踩雷（0 无雷 ~ 满雷爆炸）
  ▸ [建议] 行动建议：此时该做什么（哄、冷、皮、跑...）

步骤5：挑选回复
  系统给出【稳妥型】【幽默型】【高冷型】(可选发疯/更疯/冒犯)等多种风格，
  点击回复风格按钮即可自动复制到剪贴板，直接回消息。


================================================================================
五、世界书（知识包）系统
================================================================================

【是什么】
  世界书就是给每个"角色/世界观"注入的专属设定档。
  比如你和朋友聊"明日方舟"，就让 TA 挂上《明日方舟》世界观；
  转头和长辈聊天，就切到"长辈相处"设定。互不污染，切换自如。

【如何使用】

  1. 打开管理面板
     桌面版顶栏点[书架]（世界书架）打开「📚 多世界书管理」。
     面板结构：左侧知识包列表 / 中间 JSON 编辑器 / 下方启用勾选 + 按钮行。

  2. 新建一本
     点[➕ 新建] -> 输入书名 -> 得到一份 {"name","description","terms"} 的 JSON 骨架。
     直接在编辑器里改 JSON 即可：description 写世界观背景，terms 写黑话词典。

  3. AI 编书（推荐）
     点[AI 编书] -> 输入主题（如"明日方舟 世界观"）-> 再起个书名。
     系统会联网搜索该主题 -> 交给大模型提炼成 description / terms / blacklist -> 自动落盘。
     生成后内容会直接加载到编辑器里，可以继续手工微调再点[💾 保存]。

  4. 挂载到会话
     勾选[✅ 作为当前会话启用] 再保存，这本书就写进 config.json 的
     selected_lorebooks，发消息时作为背景注入 AI 上下文。

  5. 存储位置
     每本书 = ~/.cf_assistant/lorebooks/<书名>.json 一个文件，
     文件名就是书名，可以直接备份/拷走/发给别人。

【删除书】
  列表里选中 -> [🗑️ 删除]，会同时从 selected_lorebooks 里摘掉，不残留配置。
  "默认"这本不可删。


================================================================================
六、联网查梗 —— 不懂的黑话一问便知
================================================================================

在[世界书管理]里点击[🔍 联网查梗]，输入一个词，例如"佩洛"、"电棍"、"嘉心糖"，
系统会依次尝试 DuckDuckGo / Bing / 百度（自动回退，一个挂了换下一个），
把标题 + 摘要 + 链接列在只读窗口里，供你复制进知识包的 terms。

  ▸ 它只负责"查"，不会自动改写你的书；要自动成书请用上面的[AI 编书]。
  ▸ 搜索走的是公开网页接口，偶尔会被限流；换关键词或过一会儿再试。

七、API 配置指南（三种模式通用）
================================================================================

所有模式共享配置文件： C:\Users\你的用户名\.cf_assistant\config.json

支持的接入方式：

  ▶ 云服务商 API：
      如 DeepSeek、Kimi、通义千问、智谱等。
      在[设置]里填入对应的：
      - API 地址（如 https://api.deepseek.com/v1）
      - API Key（对应平台申请）
      - 模型名

  ▶ 校园 API：
      部分高校为师生提供大模型接口。
      根据学校网络信息中心提供的文档，填入地址、Key、模型名即可。
      注意：部分校园接口返回的是纯文本而非 JSON，本版本已做[纯文本自动回退]
      —— 若返回非 JSON，会自动按标签格式（【稳妥型】等）解析出多风格回复，
      不会直接报错。

  ▶ 本地 Ollama / LM Studio：
      填 http://localhost:11434/v1（Ollama）即可，
      Key 填 ollama 或任意字符（本地一般不做鉴权），
      模型名填你下载的模型，如 deepseek-r1:14b 或 qwen2.5:7b。

【多套配置自由切换】
  设置面板底部可添加/维护多套 Provider 配置。
  前缀勾选或下拉切换即时生效，无需重启。

【代理说明】
  engine 调用模型时用的是 trust_env=False 的 httpx 客户端，
  即"系统代理不生效"。如果你的网络必须走代理，请把代理地址写进
  API 地址本身，或改成在代码里显式传 proxies。


================================================================================
八、人设与风格 —— 进阶玩法
================================================================================

  ▸ 个人风格克隆：设置 ->[✨ 一键提取我的风格]。
    粘贴你的历史发言（越多越好），系统提取语气特征并保存，
    回复会自动模仿你的说话方式。

  ▸ 生成式头像：设置 ->[[生成] 生成头像]。
    系统会按你的描述生成 Google 风格 / Meta 风格的头像，
    并自动保存到本地配置，聊天窗口即时显示。

  ▸ 表情包建议：当你选了[[夸张笑] 搞笑]等心情，回复里会附带
    情景适用表情包提示（仅供脑补，实际发送需你手动找图）。

九、常见问题排错
================================================================================

1. 快捷键没反应？
   -> 右键启动脚本选[以管理员身份运行]。

2. 双击 bat 没反应？
   -> 检查 Python 是否加入 PATH；或先跑一遍[1-首次启动（检查环境）.bat]。
   -> 被 Windows Defender 拦截时，去[保护历史记录]恢复并添加信任。

3. 一直转圈 / 分析慢？
   -> 云端接口慢：检查 API Key 余额，换更快的轻量模型。
   -> 本地接口慢：确认 Ollama 模型已加载（ollama ps 查看）。
   -> 同时把[上下文记忆轮数]调小（设置 -> 高级设置）。

4. 报"分析失败"？
   -> 云端：检查 API Key / 余额 / 网络。
   -> 校园接口：确认返回是非 JSON 文本时会自动触发纯文本回退。
   -> 本地：确认服务已启动且模型名拼写无误。
   -> 具体原因看 cf_app_log.txt 的最后几行。

5. 手机连不上 Web 版？
   -> 确认手机和电脑连同一个 Wi-Fi（校园网可能开 AP 隔离，改用热点）。
   -> 确认 IP 格式正确：http://电脑IP:8000，不要用 https / localhost。
   -> 防火墙放行 python.exe（专用+公用都勾上）。

6. 世界书导入失败？
   -> 确认 JSON 为合法 UTF-8，结构至少包含 name / description / terms 字段。

7. 联网查梗没结果？
   -> 先跑 `python -c "from engine import web_search; print(web_search('测试',1))"`；
   -> 如果报 duckduckgo_search 缺失，说明没装依赖（pip install -r requirements.txt）；
   -> 如果三条搜索线全挂，通常是网络问题，换个网络环境再试。

十、文件与备份说明
================================================================================

运行过程中可能生成/修改的文件（建议定期备份）：

  C:\Users\你的用户名\.cf_assistant\
    ├── config.json                <- 所有配置（API、人设、世界书勾选、会话列表）
    ├── lorebooks\<书名>.json      <- 每本世界书一个文件
    ├── history_<会话名>.json      <- 每个会话的分析历史（含你的真实聊天记录！）
    └── context_<会话名>.json      <- 上下文记忆

  D:\Projects\ck_assistant_v3.0\
    ├── engine.py                  核心逻辑（不要手动改，除非你懂）
    ├── engine_config.py           配置读写底座
    ├── _debug_logger.py           日志落盘（engine/main 都会 import，别删）
    ├── ui.py / ui_settings.py     主界面 / 设置面板
    ├── main.py                    桌面版入口（全局热键、托盘）
    ├── api.py                     Web 版后端（FastAPI，端口 8000）
    ├── index.html                 Web 常规版前端
    ├── galgame.html               Galgame 版前端
    ├── requirements.txt           依赖清单
    └── README.txt                 本文件

  .bak_* 历史备份与 _fix*.py 临时脚本已在 2026-11 清理；
  需要旧版本可从 git 历史取回（git log --all -- <文件名>）。

  ⚠ history_*.json 里是真实聊天记录、config.json 里是明文 API Key，
    两者都不要提交到任何仓库（.gitignore 已经挡住 config.json）。
