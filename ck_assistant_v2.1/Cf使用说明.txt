========================================
      💬 Cf 聊天助手 v2 - 使用说明书
========================================

【关于本次更新】
如果你是老用户，直接下滑到“⭐ v2 新增功能”部分即可，基础操作和快捷键保持不变。

----------------------------------------
⭐ v2 新增功能（老用户必看）
----------------------------------------
1. 多会话隔离（顶栏下拉框 + “+”号）
   - 每个人一个专属档案！点击顶栏黄色的会话框，可以切换不同的聊天对象。
   - 点击旁边的“+”号可以新建会话（比如“张三”、“李四”、“摸鱼群”）。
   - 每个会话的上下文记忆和历史记录是完全隔离的，互不干扰。

2. 上下文记忆（设置 -> 高级设置）
   - 现在 AI 能记住你们之前聊了什么，分析更连贯。
   - 可以通过滑块调整“记忆轮数”（0-10轮，默认4轮）。
   - ⚠️ 严重警告：轮数越多，消耗的 API Token 越多，本地模型推理也会越慢！建议保持在 3-5 轮。
   - 右下角新增“🧠 清空当前记忆”按钮，点一下让 AI 重新失忆。

3. 个人风格模仿（设置 -> 个人风格）
   - 在设置里填入你平时的说话习惯（比如：喜欢用短句、爱用“绝了”“老铁”、不用感叹号）。
   - AI 生成回复时，会尽量带入你的个人风格，让回复看起来像是你自己说的。

4. 界面微调
   - 去掉了右键关闭（防止右键粘贴误触），新增了右上角“✖”关闭按钮。
   - 历史记录面板会跟随当前会话切换（点击📜查看）。

----------------------------------------
【核心快捷键】
----------------------------------------
Ctrl + Shift + J ：提取输入框或剪贴板的内容，开始分析
Ctrl + Shift + S ：打开设置面板（配置API、换背景、调记忆）
Ctrl + Shift + Q ：彻底退出 Cf 助手

【悬浮窗操作】
- 拖动窗口：按住窗口任意空白处拖动
- 调整大小：拖动右下角绿色小方块
- 关闭窗口：点击右上角 ✖ 按钮，或按 Esc 键
- 复制回复：点击分析结果下方的任意回复按钮

----------------------------------------
【首次运行配置】
----------------------------------------
1. 解压整个文件夹到一个没有中文和空格的路径（比如 D:\Cf助手）。
2. 找到并右键点击 “1-首次启动（检查环境）.bat”，选择 “以管理员身份运行”。
3. 等待黑框自动安装依赖（1-2分钟），首次配置完成后悬浮窗会自动弹出。
4. 点击右上角 ⚙️ 按钮，填入你的 API Key（云端模式）或确认本地 Ollama 配置。
5. 建议在“个人风格”里填写你自己的说话习惯，体验更佳。

【日常使用】
直接双击 “2-日常启动（静默版）.bat”。黑框一闪而过，直接弹出悬浮窗。如果快捷键失效，请右键以管理员身份运行。

----------------------------------------
【常见问题排错】
----------------------------------------
1. 双击没反应 / 快捷键失效？
   解答：权限不够，请右键以管理员身份运行脚本。
2. 一直被 Windows 拦截？
   解答：Windows Defender 会误报，请前往“保护历史记录”恢复并添加信任。
3. 水群模式分不清谁在说话？
   解答：微信直接框选复制不带昵称。请右键群友发言 -> 引用，再复制。
4. 换了背景图没保存？
   解答：选好背景后，务必点击设置最下方的“保存配置”按钮。
5. AI 回复变得很啰嗦或者脱离现实？
   解答：可能是上下文记忆太长，导致 AI 思维混乱。点击右下角“🧠 清空当前记忆”即可解决。
6. 账号安全吗？
   解答：所有数据（API Key、历史记录、上下文、背景图）都保存在你电脑本地（C:\Users\你的用户名\.cf_assistant），绝对隐私。
